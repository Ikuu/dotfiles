# dotfiles

Managed with [chezmoi](https://www.chezmoi.io/). Desktop is
[Umbriel](https://docs.noctalia.dev/umbriel/) (Wayland compositor) with the
[Noctalia](https://docs.noctalia.dev/) shell, on CachyOS with an AMD GPU.

## Setup

```sh
chezmoi init --apply ikuu/dotfiles
```

Expects these to be installed: `umbriel`, `noctalia`, `ghostty`, `fish`,
`waterfox`, `dolphin`, `kate`, `btop`, `mpv`, `yt-dlp`, `grim`, `slurp`,
`satty`, `jq`, `wl-clipboard`, `python`.

## What's here

| Path | What |
| --- | --- |
| `.config/umbriel` | Compositor config, split into `cfg/*.toml`, plus helper `scripts/` |
| `.local/state/noctalia/settings.toml` | Noctalia's live settings (see below) |
| `.config/noctalia` | Noctalia colours and plugins |
| `.config/environment.d` | Session environment: Proton/HDR/shader cache (`gaming.conf`), MangoHud |
| `.config/ghostty` | Terminal (themed by Noctalia) |
| `.config/mpv` | mpv, including an HDR profile |
| `.config/fish`, `starship.toml`, `fzf` | Shell |
| `.config/nvim`, `yazi`, `satty`, `fastfetch`, `fontconfig` | Other tools |
| `.local/bin` | Scripts, e.g. `dot-screenshot` |

## Umbriel

`config.toml` only includes the files in `cfg/`:

| File | Contents |
| --- | --- |
| `autostart.toml` | Apps started at login |
| `display.toml` | DP-1 (3440x1440@165, HDR auto) and DP-2 (2560x1440@165) |
| `input.toml` | Flat mouse accel, focus follows mouse, workspace back-and-forth |
| `keybinds.toml` | All keybinds (defining the table replaces Umbriel's defaults) |
| `layout.toml` | Scrolling layout, 50% default column width, 5px corners |
| `rules.toml` | Window/layer rules, drop-down terminal, startup layout |
| `animation.toml` | Hot corner, scratchpad dim off |
| `misc.toml` | Environment (Qt theme etc.), cheatsheet off at startup |

`noctalia.toml` is generated by Noctalia from the wallpaper colours and is
ignored by chezmoi. Most changes apply on save; autostart and environment
changes need an Umbriel restart. Check edits with `umbriel config validate`.

### Scripts

- `scripts/scratchpad-autohide.py` (autostart): hides a scratchpad when its
  last window closes, and resizes/centres scratchpad windows on whichever
  monitor they open. `WIDTH`/`HEIGHT` must match `default_floating_size` in
  `rules.toml`.
- `scripts/column-fill.py` (`Mod+Ctrl+F`): Umbriel has no "expand to available
  width", so this computes it. Assumes `gap = 8` and `border_width = 2`;
  update `GAP`/`SLOT_EXTRA` if those change.
- `scripts/startup-obsidian.sh` (autostart): starts Obsidian after Discord so
  workspace 2 is Discord left, Obsidian right. Startup rules only match in
  the first 60s.
- `~/.local/bin/dot-screenshot`: works under Umbriel (uses
  `umbriel focused-window` / `umbriel outputs`) and Niri.

## Noctalia

Noctalia reads `~/.local/state/noctalia/settings.toml`, not
`~/.config/noctalia/settings.json`. Change settings with:

```sh
noctalia msg config-get lockscreen        # dump a section
noctalia msg config-set bar.default.margin_ends 650
```

Changed from defaults: lock screen transition off, bar shortened, network
name hidden.

## HDR

- DP-1 uses `hdr = "auto"`: SDR desktop, HDR only for fullscreen content with
  HDR metadata. The monitor goes black for 2-3s when it switches.
- mpv: `vo=gpu-next` + `target-colorspace-hint`, and an auto `[hdr]` profile
  that targets PQ at 1000 nits so HDR videos actually trigger HDR.
- Proton: `PROTON_ENABLE_WAYLAND=1` and `DXVK_HDR=1` in `gaming.conf`. Games
  running through XWayland can't trigger HDR. Per game, `DXVK_NO_HDR=1`
  turns it off and `PROTON_ENABLE_WAYLAND=0` falls back to XWayland.
- Check with `umbriel color | head -3`: `active yes` means HDR is on.
